# Interactive-Recipe-Website

## Overview
An interactive recipe web application that uses JavaScript DOM manipulation to dynamically display recipes, filter search results, and enhance user interaction without reloading the page.

## Features
- Recipe search
- Dynamic recipe display
- Recipe detail view
- Ingredient checklist
- Print recipe functionality
- DOM manipulation
- Event listeners

## Technologies
- HTML5
- CSS3
- JavaScript

## Skills Demonstrated
- JavaScript
- DOM Manipulation
- Event Handling
- Dynamic User Interfaces
- Front-End Development

## Project Outcome
Developed an interactive web application that provides a seamless user experience using client-side JavaScript.
